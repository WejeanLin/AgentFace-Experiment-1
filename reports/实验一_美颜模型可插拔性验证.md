# 实验一：美颜模型可插拔性验证

## 1. 实验目的

本实验的重点不是比较哪个模型“最好”，而是验证：**AgentFace 的美颜模型位置可以随时替换；替换为不同的开源模型后，整个离线美颜流程仍然可以正常运行。**

换句话说，框架的输入、提示词、参数和输出保存方式不变，只替换模型名称或模型路径，就能够得到不同风格的美颜结果。

## 2. 使用的模型及观察重点

| 插入模型 | 可以观察的特点 | 最适合展示的内容 |
| --- | --- | --- |
| RealVisXL V5 | 皮肤净化 / 瑕疵修复 | 疤痕、痘印、局部皮肤缺陷消除 |
| Juggernaut XL v9 | 皮肤质感 / 微纹理 | 毛孔、细纹、真实肤质、光影层次 |
| CyberRealistic XL | 五官细节 | 眼睛、眼周、嘴唇、面部结构清晰度 |
| epiCRealism XL | 整体人物真实性 | 整张脸自然度、人物照片感 |

上表是每个模型在对比图中建议观察的方向，不是本实验对模型优劣的排序，也不构成“某模型一定更好”的结论。

## 3. 实验输入与输出

输入为仓库中的四张示例人像：

```text
samples/portrait_01.jpg
samples/portrait_02.jpg
samples/portrait_03.jpg
samples/portrait_04.jpg
```

每张图片分别经过四个模型处理，因此共生成：

```text
4 张图片 × 4 个模型 = 16 张效果图
```

结果按图片保存：

```text
outputs/
├── portrait_01/
│   ├── RealVisXL_V5.png
│   ├── Juggernaut_XL_v9.png
│   ├── CyberRealistic_XL.png
│   └── epiCRealism_XL.png
├── portrait_02/
├── portrait_03/
└── portrait_04/
```

为方便查看，还生成了五张对比图：一张总览图
`outputs/comparisons/experiment_1_overview.png`，以及四张按输入图片分开的对比图。每张对比图均按下列顺序排列：

```text
原图 | RealVisXL V5 | Juggernaut XL v9 | CyberRealistic XL | epiCRealism XL
```

## 4. 保持不变的实验条件

除了模型本身外，所有可影响生成结果的主要条件均保持一致：

| 条件 | 固定值 |
| --- | --- |
| 输入图片 | 同一组四张示例人像 |
| 美颜提示词 | 同一条提示词 |
| 负面提示词 | 同一条负面提示词 |
| 图片尺寸 | 1024 × 1024 |
| 推理步数 | 20 |
| Guidance scale | 5.0 |
| Denoising strength | 0.25 |
| 随机种子 | 42 |
| 输出规则 | `outputs/<图片名>/<模型名>.png` |

完整的提示词、模型路径和参数记录在
[`config/experiment_1.json`](../config/experiment_1.json) 中。

## 5. 实验怎么做

本实验没有启动网页、FastAPI 或数据库服务，而是直接调用统一的离线 SDXL Img2Img 推理脚本。流程如下：

```text
读取样本图片
    ↓
使用固定的美颜提示词和参数
    ↓
选择一个美颜模型
    ↓
生成效果图
    ↓
按统一规则保存结果
```

运行脚本为 [`code/run_model_swap.py`](../code/run_model_swap.py)。该脚本从同一份配置中读取四个模型；每次只改变模型目录或单文件权重，其他推理逻辑不变。运行前先检查四个模型的必要组件是否完整，确认全部 `READY` 后再生成图片。

CyberRealistic XL 使用单文件 checkpoint，其他三个模型使用 Diffusers 目录格式；两种格式都由同一个 SDXL Img2Img 流程处理。这正是本实验需要验证的“统一接口下可替换模型”的实际情况。

服务器为共享显存环境，因此运行时启用了 CPU offload 以降低显存占用。该设置只影响模型在 CPU/GPU 间的内存放置，不修改提示词、随机种子、步数、尺寸或任何生成参数。

## 6. 结果核验

运行前检查显示四个模型均为 `READY`。生成完成后，对结果进行了以下核验：

- 已生成 16/16 张结果图；
- 每张结果图尺寸均为 1024 × 1024；
- 对每张输入图，四个模型的输出文件 SHA-256 均不同；
- 已生成 5 张对比图；
- 四张输入图与 16 张结果图的大小和 SHA-256 均记录在
  [`runs/experiment_1_manifest.json`](../runs/experiment_1_manifest.json) 中。

这些检查说明四个模型均成功被载入同一流程，并各自完成了对应的输出生成。对比图可用于按第 2 节的观察方向查看皮肤、微纹理、五官细节和整体人物真实感的差别。

## 7. 实验结论

实验一完成了四个开源美颜模型的接入和完整离线推理：RealVisXL V5、Juggernaut XL v9、CyberRealistic XL 与 epiCRealism XL 均使用同一套输入和推理流程，生成了全部 16 张效果图。

因此，本实验支持如下结论：**AgentFace 可以通过统一的模型接口接入并替换多个不同的开源美颜模型，而无需修改整体美颜流程。**

本实验的结论限于“模型可插拔性”和“流程可运行性”。它不以此证明某个模型在所有人像、所有皮肤问题或所有审美标准下绝对最好；如需比较效果优劣，应另行设计有人工评分或客观指标的评价实验。

## 8. 复现说明

模型权重未上传到本公开仓库。复现时需要按照
[`config/experiment_1.json`](../config/experiment_1.json) 准备四个模型的权重，并遵守各模型发布者的许可证和使用要求；之后安装
[`requirements-offline.txt`](../requirements-offline.txt)，运行：

```bash
python code/run_model_swap.py --check
python code/run_model_swap.py
```

公开仓库保留了输入样本、结果图、对比图、统一脚本、固定配置和哈希清单，便于查看和核验本次实验的输出。
